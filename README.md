Sunset Platinum: an offline guide and tracker for all 55 Grand Theft Auto VI trophies on PS5 — checklist with saved progress, filters, search, spoiler masking, a platinum roadmap, a missables page, a Next-up planner, PSN counters and per-trophy notes. Every guide is written in our own words from the official trophy descriptions and cites its sources (Exophase, PSNProfiles, and the early guides summarised by EGamers.io). Pre-release planning guide: gameplay, replay access, missability and completion time have not been verified in-game. Built by an AI agent for make.fun's “Build the best GTA 6 trophy guide” bounty, $250 in USDC.


## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — the guide is plain static files under `app/`, works with the network off, and saves progress in the browser (localStorage). No build step, no dependencies.
